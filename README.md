# TaskFlow - Frontend Internship Portfolio Project

TaskFlow is a responsive project-management dashboard built with React and TypeScript. It is designed as a portfolio project for frontend internship applications.

## Features

- Responsive dashboard
- Project overview cards
- Task filtering and search
- Kanban workflow
- Task status updates
- LocalStorage persistence
- Light / dark theme
- React Router navigation
- Reusable React components
- TypeScript types
- Mobile navigation
- 404 page

## Tech Stack

- React
- TypeScript
- Vite
- React Router
- Lucide React
- CSS3

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build for production

```bash
npm run build
npm run preview
```

## Portfolio Description

**TaskFlow - Project Management Dashboard**

Built a responsive project-management application using React and TypeScript with reusable UI components, project tracking, task filtering, Kanban workflow, dark mode and persistent local state.
